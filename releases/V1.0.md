# V1.0 稳定基线

确认日期：2026-10-26（Asia/Shanghai）
Git 回退标签：`v1.0`

## 功能范围

- B站、小红书视频链接导入；公众号正文读取；音视频和文字导入。
- 本机 Whisper 转写、时间戳、本地 Ollama 摘要与问答。
- 白底蓝色界面；桌面三栏与窄屏页签切换。
- 独立资源库：封面、标题、来源、状态、已有摘要预览与详情。
- 多选导出 ZIP：Markdown 或纯文本，包含原文与已有摘要。
- 浏览器授权本地保存目录，保存媒体、封面、转写与摘要；从目录恢复资源。
- 不支持目录授权的浏览器使用 ZIP 下载。

## 已知边界

- 轻量本地模型可能曲解内容，摘要和问答需要核对原文。
- 当前并未公开部署；公开网页连接用户本地引擎的配对尚未实现。
- 当前 `data/` 仍保留本机工作文件，用户选择的目录保存资源副本。
- 运行环境、模型与资源不纳入 Git；代码回退不回滚或删除用户文件。
- 第三方依赖清单见 requirements.lock.txt；XHS-Downloader 源码版本记录在 README.md。

## 回退约定

后续用户要求回退而未指定版本时，以 `v1.0` 为准。先保存当前代码，再恢复该标签的代码及依赖清单。保留 data/、vendor/、运行环境和用户所选目录，不运行会清理这些目录的命令。
