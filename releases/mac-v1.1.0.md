听读首个 Mac 桌面预览版，适配 Apple Silicon（M 系列）。

安装：下载 DMG，将「听读」拖到「应用程序」后启动。无需另装 Python、FFmpeg 或 Ollama，内置离线语音、降噪、发言人标记和轻量总结模型。首次启动需要整理模型，建议预留至少 5 GB 磁盘空间。

- 录音转写：暂停/继续、逐段原文、发言人临时标记、自由总结、问答、分类及批量导出/删除。
- 导入与阅读：链接、本地音视频和文字；平台限制可能导致导入失败。
- 资源库与录音历史独立管理，作者订阅支持分页及批量转写。
- 数据位于 `~/Library/Application Support/听读/data/`，不会自动迁移源码版历史。

限制：未使用 Apple Developer ID 签名或公证；只有本地完整性签名，首次启动可能需要在「系统设置 → 隐私与安全」允许打开。不要关闭系统安全保护。当前在 macOS 26.3.1 ARM64 上验证，其他版本、Intel Mac 与 Windows 未实机验证。麦克风授权和实际设备收音请安装后本人试录；开发测试使用合成音频，未开启真实麦克风。摘要和临时发言人标记需核对原文。

检查：78 项 Python 检查、录音/暂停/导出前端检查、打包后 FFmpeg + SenseVoice 实际推理、XHS 子进程依赖检查，以及独立桌面窗口启动。线上平台下载不保证每条内容可访问。

公开源码为干净快照，不包含个人资源、登录状态、管理口令或旧资源截图。第三方组件和模型许可证见源码 `third_party/`。
