# 云端 1.1.1-cloud.1

仅用于 `server-2gb` 的个人密码保护测试环境。

- 云端通过独立页面注入隐藏导入和订阅的本机浏览器登录控件，订阅重试按钮改为刷新列表。桌面默认 local 页面仍返回原始静态文件。
- 录音原声保存完成不代表发言人和总结处理结束。历史记录和详情补充后台状态；删除前重新检查所选记录，处理中的记录明确提示，保留文件。
- 云端删除获取记录锁最多等待 2 秒；发言人缓存清理由后续音频任务处理，不为删除启动模型或等待其他模型任务。删除请求等待超时后提示刷新核对，不宣称删除成功。
- 完整删除仍实际移除处理目录；仅删除音频仍保留转写和总结。另存目录及导出副本不自动删除。

## 渠道隔离

版本记录见 `channels.json`。云端专属脚本 `static/cloud-client.js` 仅由 `cloud_ui.py` 注入；本机和桌面路径不注入。现有 Mac 安装包、已安装应用和桌面发布标签保持不变。

## 验证

覆盖 local HTML 逐字节不变、cloud HTML 注入、后台占锁及时拒绝删除、模型繁忙时缓存清理不等待、进行中任务删除前拦截、物理文件删除、音频删除后保留文字，以及录音暂停/继续。
